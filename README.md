# odu

<img src="./logo.svg" width="112" align="right" alt="odu — a CI runner you attach to" />

**Live, attachable CI for [`just`](https://just.systems) recipe DAGs.**

[Website](https://juspay.github.io/odu/) · [Documentation](https://juspay.github.io/odu/docs/) · [Announcement](https://kolu.dev/blog/odu/)

```sh
nix run github:juspay/odu -- run
```

Run locally by default, fan out across machines when configured, and attach from another terminal—or a coding agent—while the pipeline is live.

AGPL-3.0-or-later
